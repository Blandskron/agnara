    1. Primera ejecución

    En un entorno de Python 3.14 o posterior, instala el núcleo. Añade los adaptadores que necesites con la misma versión.

    python -m pip install agnara==1.0.4

    El ejemplo declara una suma con permiso obligatorio y salida entera. Compila su plan una vez, construye un contexto por llamada y cierra el contenedor al terminar. La identidad se construye localmente para el ejemplo. En un servicio real el host la obtiene de su autenticación.

    import asyncio
from agnara import Agnara, Principal
from agnara.di import DIContainer, DIRegistry
from agnara.execution import (
    ExecutionContext, ExecutionPlan, Failure, FailureCode,
    Invocation, Success, invoke_result,
)

async def main():
    app = Agnara("calculator")

    @app.capability(scopes={"calculator:use"}, output=int)
    def add(a: int, b: int) -> int:
        return a + b

    registry = DIRegistry()
    plan = ExecutionPlan.compile(app.compile()["calculator.add"], registry)
    container = DIContainer(registry)
    actor = Principal("demo", scopes={"calculator:use"})

    async def call(a, principal):
        invocation = Invocation(plan.definition.id, {"a": a, "b": 3}, {})
        context = ExecutionContext(invocation, container, principal=principal)
        return await invoke_result(plan, context)

    try:
        ok = await call(2, actor)
        denied = await call(2, Principal("guest"))
        malformed = await call(True, actor)
        assert isinstance(ok, Success) and ok.value == 5
        assert isinstance(denied, Failure) and denied.code is FailureCode.FORBIDDEN
        assert isinstance(malformed, Failure)
        assert malformed.code is FailureCode.INVALID_INPUT
        print(ok.value, denied.code.value, malformed.code.value)
    finally:
        await container.aclose()

asyncio.run(main())

    Resultado verificado 5 forbidden invalid_input. La segunda llamada carece del permiso requerido. La tercera aporta un booleano donde el contrato exige un entero.

    Para componer HTTP, declara una ruta con Http y los argumentos con Binding. Para MCP, publica la misma capacidad con Mcp.tool y construye el servidor con build_mcp_server.

    Agnara

    Clase · Estable · agnara

    Punto de entrada de una aplicación. Registra capacidades propias, monta contextos con include() y congela la colección con compile(). Su nombre funciona como espacio de nombres de las capacidades que declara directamente.

    Agnara(name: str) -> None
    Parámetros
    name
    Nombre lógico de la entidad que se declara, describe o publica.

    Importa Agnara para el proyecto y App para un contexto delimitado. El registro es mutable durante el arranque. La compilación cierra la declaración de capacidades.

    Nombre de la aplicación y espacio de nombres de sus capacidades directas. str

    Accede al registro de capacidades declaradas. CapabilityRegistry
