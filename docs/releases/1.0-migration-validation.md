# V1-43: A8-to-1.0 migration and validation record

## Scope and source revision

This record covers the V1-43 documentation and clean-room validation work
started from `496f28b94caa7dd3b1cfeb5fbf8c90a5d9c87744` on `develop` (the merge
of PR #479). It does not publish a distribution, create a tag, merge a branch,
or approve a protected environment.

`docs/MIGRATION_A8_TO_1_0.md` is the reader-facing migration path. It maps the
pre-stable changes to their 1.0 contract, with public examples for import
spelling, DI, introspection, authority, execution identity, explicit direct
idempotency, same-snapshot composition, streaming/SSE, embedding and HTTP
composition. The canonical inventory remains `docs/public-api.json`; historic
A8 release notes and ADR/RFC records were intentionally not rewritten.

## Documentation reconciliation

- The root README and the kernel package README now distinguish the retained A8
  publication baseline from the candidate 1.0 target and link the migration
  guide.
- The quick-start and HTTP examples no longer prescribe old alpha installs.
- `docs/HTTP_COMPOSITION.md`, `docs/MATURITY.md`, `docs/INTEROPERABILITY.md`,
  `docs/API_DESIGN.md`, and the HTTP composition module now agree that the
  fourteen `agnara_http` package-root exports are stable 1.x spelling. They
  retain the actual non-goals: no third-party provider extension or public
  discovery composition API, no WebSocket/MCP stream projection, and no
  streaming request body contract.
- `tests/release/test_a8_to_1_0_migration_guide.py` makes the key migration
  boundaries and the absence of old install commands regression-tested. The
  public-import audit scans the guide itself.
