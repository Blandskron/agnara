# Agnara 1.0.4

Agnara 1.0.4 packages the current synchronized 1.x development line after the 1.0.3 publication baseline.

This release includes the reviewed CLI diagnostics and output-safety fixes, the provisional A2A surface and conformance evidence, lifecycle and cancellation coverage, OpenAPI output schema improvements, dependency security updates, and refreshed documentation and workflow pins.

The seven first-party distributions share version 1.0.4. Publication is performed by the protected workflow in three phases: bootstrap-1, bootstrap-2, and final. This document describes the candidate; the workflow and PyPI verification establish publication status.
