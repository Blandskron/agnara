# Agnara 1.0.3 — Documentation Baseline

Agnara 1.0.3 aligns project documentation and package metadata with the
stable 1.x framework that the repository implements.

Runtime behavior and public API are unchanged. The release:

- establishes current documentation as the primary source for usage and limits;
- removes superseded prerelease, migration and publication-recovery documents;
- corrects PyPI-facing descriptions and maturity metadata;
- updates examples, security and interoperability guidance to current evidence;
- consolidates release and maintainer instructions for the seven synchronized
  distributions.

The minimum Python version remains 3.14. HTTP, MCP, CLI and telemetry are
separate distributions. A2A and events remain reserved namespaces without
public runtime APIs. Publication status is established by the protected release
workflow and package-index verification, not by this source document alone.
