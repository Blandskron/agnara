# 1.0.0 public API classification — decision and evidence

`docs/public-api.json` is the exact public contract. This record explains the
decision represented by that manifest; the generated API reference is a
reader-facing projection, not a second contract.

## Decision

The 1.0 Python surface contains **166 stable names across 13 governed modules**.
Each name has exactly one canonical import path. The two empty reserved
namespaces, `agnara_a2a` and `agnara_events`, remain governed so that adding a
first export cannot bypass review.

The 171 duplicate import paths previously exposed through leaf-module
`__all__` declarations are no longer public. Their implementation modules may
remain importable as ordinary Python modules, but they are not classified and
must not be used in examples, generated projects, or compatibility promises.

## Pre-stable spelling decisions

### Dependency injection

`agnara.di` is the stable DI entry point. The former `agnara.core.di` path is
an implementation path and no longer declares a public export list.

```python
# Before
from agnara.core.di import DIRegistry, provider

# 1.0
from agnara.di import DIRegistry, provider
```

### Introspection snapshots

`IntrospectionSnapshot.applications` and the JSON `applications` member name
the compiled applications in a snapshot. This replaces the ambiguous snapshot
`apps` member; `ApplicationDescriptor.apps` still describes the bounded
contexts mounted by one application.

```python
# Before
for application in snapshot.applications:
    ...

# 1.0
for application in snapshot.applications:
    ...
```

Consumers of serialized snapshots must read `applications` instead of `apps`.
The snapshot format is explicitly versioned; consumers must reject an
unsupported format version rather than guess at field names.

## Coverage and artifact evidence

The manifest gate checks source `__all__` declarations in both directions, the
public-import scanner covers examples, guides and generated projects, and the
installed-artifact gate imports every stable manifest name. The five names that
previously lacked direct references — `JsonSchema`,
`IdempotencyConflictError`, `IdempotencyInProgressError`, `VisibilityRule` and
`McpPrincipalMapper` — have direct import-smoke coverage in this task.

No alias path is deprecated: it was removed from the declared public surface
before 1.0, so it receives no 1.x compatibility promise. This is an intentional
pre-stable migration recorded in `CHANGELOG.md`.
