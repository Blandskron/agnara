# Agnara v1.0.1 — Synchronized Security Patch

`1.0.1` publishes the synchronized post-baseline patch set across all seven
first-party distributions.

Upgrade all installed Agnara distributions together to `1.0.1`.

## Security fixes

- Directly constructed execution plans must include declared scope,
  application and confirmation policies; direct and MCP calls can no longer
  bypass capability authorization.
- Caller-facing authorization denials redact missing scope labels while
  preserving opt-in operator diagnostics.
- Viewer-specific discovery and Explorer responses now require whole-response
  `private` or `no-store` cache directives to prevent shared-cache replay.
- Publication routes now match HTTP methods case-sensitively so malformed or
  lowercase variants cannot reach GET-only schema, documentation, discovery or
  Explorer content.

## Release hardening fix

- The phased release workflow is pinned to one successful first-phase
  candidate commit and validates published PyPI file SHA-256 values against
  retained build hashes before publication can continue.

Full change record: `CHANGELOG.md`, section `[1.0.1]`.
