# 1.0 integrated dogfooding (V1-42)

## Scope

V1-42 proves the four deployment modes from ADR 0094 with compact consumer
programs. They are copied outside the repository and run with `python -I` only
after a fresh Python 3.14 environment installs the seven candidate wheels.
They import only names classified in `docs/public-api.json`; the same public
import checker used for repository examples audits the copied programs.

The programs deliberately remain test fixtures, not a new integration package
or an expanded support claim:

| Consumer | Mode and evidence |
| --- | --- |
| `tests/reference_apps/standalone.py` | Core-only unary execution, nested composition, runtime execution identity, explicit idempotent result reuse, non-idempotent repeated effects, typed streaming, cancellation, post-partial redacted failure and lifecycle telemetry. |
| `tests/reference_apps/host_sqlite.py` | Agnara as the composition root over SQLAlchemy 2.0.54 and SQLite. An application `Ledger` port encapsulates the host-owned session; no SQLAlchemy object is an Agnara handler input. |
| `tests/reference_apps/embedded_fastapi.py` | FastAPI 0.141.1 retains routing, authentication and response mapping while a native route invokes one explicit compiled Agnara runtime. |
| `tests/reference_apps/side_by_side_fastapi.py` | FastAPI native routing and an independently compiled public `Http` surface run in one host lifespan without route-table or OpenAPI merging. |

## Reproducible gate

`tests/release/test_integrated_dogfooding.py` builds all seven wheels, creates
a fresh Python 3.14 virtual environment, installs the exact consumer fixtures
(`mcp==2.1.1`, `opentelemetry-sdk==1.44.0`, `fastapi==0.141.1` and
`SQLAlchemy==2.0.54`), then installs the first-party wheels with index access
closed. It runs `check_public_imports.py`, the installed-artifact checker and
each copied consumer under isolated mode.

The gate is local evidence for the candidate under test. It does not claim a
framework plugin, a durable idempotency store, automatic retry, a synchronous
host bridge, mounted-child lifespan automation, OpenAPI merging or any new
support status. CI and maintainer review remain required for release closure.
