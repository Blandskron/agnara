# 1.0.0 release-candidate evidence

## Candidate

The first tracked commit with the exact `1.0.0` identity is
`f4adabe` (`chore(release): finalize Agnara 1.0.0 candidate`) on
`release/v1.0.0-finalization`. It was cut from `develop` at
`6447d3686b5b8f583a7127b9f30068836d24cb46` on 2026-09-22. Unlike V1-44 and
V1-45, the version transition is committed and not made in a disposable
worktree.

The only changes after `develop` are the version cut, the release
documentation and two release-test fixes (`386f633`). Three
publication-readiness tests and the dogfooding test assumed a `.dev0`
checkout and failed at the cut. There are no runtime, public-API or
dependency changes.

This record is local evidence. Branch CI on the PR and the protected release
workflow re-derive it. When they differ, their result is authoritative.
