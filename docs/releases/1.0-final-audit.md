## Scope and contract review

The audited code and architecture tests retain a frozen, transport-neutral
kernel: core does not import HTTP/framework/MCP/telemetry/schema SDKs; HTTP
and MCP project the shared compiled execution contract; identities remain
separate; idempotency has no implicit retry; and there is no durable worker,
workflow engine, scheduler or broker runtime. The version-pinned fixture
evidence is Starlette 1.6.0, FastAPI 0.141.1, Django 6.1.1, Litestar 2.24.0,
SQLAlchemy 2.0.54 and OpenTelemetry SDK 1.44.0. These are bounded fixtures,
not broad framework/ORM/exporter support claims.

The stable manifest contains 166 canonical exports across 13 modules of the
seven reviewed distributions. No public API was added, removed or renamed by
this audit.
