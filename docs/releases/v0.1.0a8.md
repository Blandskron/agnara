# Agnara v0.1.0a8 — Publication Baseline

`0.1.0a8` is the retained proof that Agnara can publish its complete,
synchronized distribution set through a reviewed workflow. It is not a
supported product baseline and does not establish a compatibility promise.

The workflow dispatches from `main`, rebuilds and verifies all distributions,
waits for approval in the protected publishing environment, and creates the
tag only after successful publication verification. Distinct publisher
environments allow the workflow to publish the complete set safely.

Future publication uses this workflow for the first product release, `1.0.0`.
See ADR 0082 and `docs/MAINTAINERS_RELEASE.md` for the operational contract.
