# Agnara v0.1.0a9 — Security Hotfix

> Never published. No `v0.1.0a9` tag, GitHub Release or PyPI upload exists.
> The remediation below ships in `1.0.0`; see `docs/releases/v1.0.0.md`.

`0.1.0a9` is an exceptional security-only hotfix based on the `0.1.0a8`
publication baseline. It remediates [GHSA-j5rx-vm8v-f7p3](https://github.com/advisories/GHSA-j5rx-vm8v-f7p3),
classified as CWE-532.

Versions `<= 0.1.0a8` could include unexpected capability exception text and
tracebacks in the default runtime logs. This release removes those details
while retaining the capability identifier for correlation. No unrelated
functional changes are included.

The next planned product release remains `1.0.0`.
